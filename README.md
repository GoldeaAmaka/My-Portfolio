## Personal Portfolio Website

This repository contains the source code for my personal portfolio website, built to showcase my data analytics, Python, and web development projects.

### Live Website
👉 https://github.com/GoldeaAmaka/My-Portfolio/

---

### Purpose
The portfolio serves as a central hub for:
- Highlighting real-world data analytics projects
- Demonstrating Python, SQL, and Pandas skills
- Presenting dashboards, notebooks, and source code
- Providing easy access for recruiters and collaborators

---

### Website Sections
- **About** – Background, education, and career interests
- **Projects** – Data analytics, dashboards, and Python projects  
- **Skills** – Python, SQL, Excel, Data Storytelling, and tools
- **Contact** – Direct links to GitHub, LinkedIn, and email
